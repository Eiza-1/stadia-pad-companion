Your Stadia controller, back in every game.

Pad Companion is a free Windows app that makes the Google Stadia controller work as an Xbox 360 controller, over the USB cable or Bluetooth. Steam, Epic, EA and every game see it straight away.

Set up in three steps

  1. Install ViGEmBus The free driver that lets games see an Xbox controller. Required. open_in_newGet ViGEmBus
  2. Install HidHide Hides the Stadia pad itself from games, so nothing reads it twice. Recommended. open_in_newGet HidHide
  3. Run the Pad Companion installer Then plug in the pad, or pair it: hold Stadia + Y for 2 seconds and add it in Windows Settings › Bluetooth & devices.
shieldThe installer isn't code-signed yet, so Windows SmartScreen may warn you. Click More info, then Run anyway. The installer checks for ViGEmBus and HidHide and offers their official pages if either is missing.

What it does

cableUSB and Bluetooth
One Xbox 360 controller to every game, whichever way the pad is connected. If both are, USB wins.
auto_awesomeGemini on the Assistant button
Type with the pad, hold to talk, or double-tap for Gemini Live, which can see your game. Uses your own free key.
vibrationRumble that feels right
Games' Xbox vibration is translated for the Stadia pad's two motors, with three profiles and a strength setting.
tuneMake it yours
Button mapping, dead zones, response curves, trigger ranges, hair trigger and profiles.
photo_cameraCapture that works
Tap for a screenshot, hold to record, with Xbox Game Bar, Steam, NVIDIA or AMD.
boltLight on your PC
A Rust core with no busy loops: about 8 MB of memory and no CPU while idle.
